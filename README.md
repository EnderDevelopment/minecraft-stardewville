# StardewVille

StardewVille is a Minecraft Bedrock Edition add-on inspired by Stardew Valley, focusing on life simulation and NPC interactions. It features a vibrant village populated with NPCs who have unique personalities, dialogues, daily routines, and behaviors. The mod includes systems for friendship, relationships, and social interactions, as well as a custom calendar with four seasons, seasonal events, and activities. Players can engage in farming, fishing, skill progression, and mission completion, all while building relationships with the NPCs. The mod also includes systems for reputation and karma, which influence interactions and dialogues. Future expansions will allow for romance, marriage, and individual NPC stories.

## Install

1. Download the `.mcaddon` file from the GitHub repository.
2. Open Minecraft Bedrock Edition.
3. Go to the "Play" screen.
4. Select "Add-Ons" from the menu.
5. Click on the "+" button to add a new add-on.
6. Navigate to the downloaded `.mcaddon` file and select it.
7. The add-on will be installed and ready to use.

## Use

1. Start a new world or load an existing one.
2. Explore the village and interact with the NPCs.
3. Engage in farming activities, fishing, and skill progression.
4. Complete missions and build relationships with the NPCs.
5. Enjoy the seasonal events and activities.
